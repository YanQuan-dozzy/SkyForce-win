# 配置和数据

## 用户数据

默认目录为 `%APPDATA%\SkyForce`：

- `data\skyforce.db`：设置、转换历史和数据库版本
- `logs\skyforce.log`：运行日志
- `legacy-imports\<时间戳>`：用户主动导入的旧项目资料

卸载程序默认保留用户数据，避免误删转换历史和设置。

## DeepSeek

AI 和弦为可选功能。设置页可配置 API Key、接口地址和模型。Key 使用当前 Windows 用户的 DPAPI 加密，不能在另一用户或另一台电脑直接解密。默认接口为 `https://api.deepseek.com`，默认模型为 `deepseek-chat`，请求超时 30 秒。

## 路径与权限

应用支持中文和空格路径。建议将输出目录设在当前用户有写权限的位置，例如“文档”或“下载”；安装目录和系统目录可能需要管理员权限。日志不记录 API Key 或乐谱全文。

## 文件限制

- 批量输入：最多 500 个
- 单个转换文件：0–10 MiB
- 编辑器/文本读取：20 MiB
- 二进制参考文件：50 MiB
- 保存数据：100 MiB
